## Continue my work

Start a new chat in your project, paste [your workboard](office/my-workboard.md) and write:

```
Start my session. Today is <date>.
```

You get the job and current draft to work on, the next action, the files it needs and the decisions that block progress. Before you stop, write:

```
Close my session
```

Save what comes back in your workboard. The chat keeps nothing for you. New company facts go through [Update the context pack](skills/marketing-ops/update-context-pack.md).

## Run Monday

Use [Monday in one chat](playbooks/weekly.md#run-monday-in-one-chat). With little time this week, use [the starter routine](playbooks/weekly.md#if-you-only-have-two-hours). If new work does not fit, [the capacity rule](playbooks/weekly.md#total-time-and-what-to-drop) says what moves.

## Paste numbers the office can use

Put this above any export. If something does not match, the office tells you what to fix instead of guessing.

```
Source: <the tool or report>
Pulled on: <date>
Period: <start date to end date>
Each row is: <one lead, one campaign line or one week>
Currency: <if there is money in it>
Stages: <as goals-and-kpis.md defines them, or say how yours differ>
Unique ID column: <its name, if there is one>
```

Pipeline numbers need MQLs, SQLs and pipeline value. Paid numbers need spend and conversions per line, and name the conversion. Campaign results need spend, leads, MQLs, SQLs and pipeline by channel.

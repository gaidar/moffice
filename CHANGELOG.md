# Changelog

## v0.1.0 – 2026-11-01

First release.

- 56 skills across the 16 marketing functions, each with a fixed format and a fictional example.
- 14 agent roles, each with a charter. Every skill has one owner.
- Context pack: 10 blank templates and one filled example for a fictional company, CogniATion.
- Office manual, output conventions, glossary and agent roster.
- Seven playbooks: starting from zero, first week, weekly, monthly, quarterly, launch, campaign lifecycle.
- Vendor setup guides for Claude, ChatGPT and Codex, Grok, and Google Gemini, verified against vendor documentation on 2026-11-01, each with a plain-chat fallback.
- Guides for filling in the context pack, using a skill, invoking an agent role, writing your own skill and keeping the office up to date, plus an FAQ.
- A 10-minute trial on a sample company, a one-hour first pass of the context pack in one file, with a founder interview route for companies with no documents, and a 3-file project setup.
- Plain requests: in a project, say what you need, and the office picks the skill and says which one. The exact prompt stays as the fallback.
- Problem-first skill finder with one filter, Copy prompt and You bring on every skill, model instructions folded on skill pages, and "How to judge this" on the strategic skills.
- Worked examples across the guides and playbooks, plus guides for judging an output and for three hard situations.
- Website with full-length pages, diagrams and a toolbar on every content page: Copy text, Open on GitHub, Raw file. Playbooks and guides, except the FAQ, also have Download PDF.
- Validator, PDF build, bundle build and a GitHub Actions workflow that deploys to GitHub Pages.

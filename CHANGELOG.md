# Changelog

## v0.1.0 – 2026-11-01

First release.

- 50 skills across the 16 marketing functions, each with a fixed format and a fictional example.
- 14 agent roles, each with a charter. Every skill has one owner.
- Context pack: 10 blank templates and one filled example for a fictional company, CogniATion.
- Office manual, output conventions, glossary and agent roster.
- Six playbooks: weekly, monthly, quarterly, first week, launch, campaign lifecycle.
- Vendor setup guides for Claude, ChatGPT and Codex, Grok, and Google Gemini, verified against vendor documentation on 2026-11-01, each with a plain-chat fallback.
- Guides for filling in the context pack, using a skill, invoking an agent role, writing your own skill and keeping the office up to date, plus an FAQ.
- Website with full-length pages, diagrams and a toolbar on every content page: Copy text, Open on GitHub, Raw file. Playbooks and guides also have Download PDF.
- Validator, PDF build, bundle build and a GitHub Actions workflow that deploys to GitHub Pages.

# Changelog

## v0.1.0 – 2026-11-01

First release.

- 57 skills across the 16 marketing functions, each with a fixed format and a fictional example.
- 14 agent roles, each with a charter. Every skill has one owner.
- Context pack: 10 blank templates and one filled example for a fictional company, CogniATion.
- Office manual, output conventions, glossary, agent roster and a one-table workboard for current jobs.
- Seven playbooks: starting from zero, first week, weekly, monthly, quarterly, launch, campaign lifecycle.
- Vendor setup guides for Claude, ChatGPT and Codex, Grok, and Google Gemini, verified against vendor documentation on 2026-11-01, each with a plain-chat fallback.
- Guides for filling in the context pack, using a skill, invoking an agent role, writing your own skill and keeping the office up to date, plus an FAQ.
- Task-first setup with three routes, an optional 10-minute trial on a sample company, a 15-minute quick start, a one-hour first pass of the context pack in one file, with a founder interview route for companies with no documents, and a 3-file project setup.
- Plain requests: in a project, say what you need, and the office picks the skill and says which one. The exact prompt stays as the fallback.
- One-chat runs: a job that needs several skills runs in one chat and shows a short working view, with the full record on request, with copyable prompts for the minimum campaign and the Monday review.
- Session prompts, job records and a Run my week page, so a new chat can resume the right draft and next step.
- A publishing handoff for campaigns and launches, with live proof recorded before anything counts as published.
- One capacity calculation across weekly, quarterly and content planning, with Not assessed when effort or days are unknown.
- A decision check in campaign, quarterly, budget and launch planning, and the last campaign's lesson as an input to the next brief.
- Measurement rules: results reported against the promised date with a separate later read, stage timing in the context pack, zero-count handling in pipeline diagnosis, no ad-tool conversions judged against a cost per MQL without a mapping, and target and baseline shown separately in weekly priorities.
- Problem-first skill finder with one filter, Copy prompt and You bring on every skill, model instructions folded on skill pages, and "How to judge this" on the strategic skills.
- Worked examples across the guides and playbooks, plus guides for judging an output and for three hard situations.
- Website with full-length pages, diagrams and a toolbar on every content page: Copy full text, Open on GitHub, Download file. Downloads are pinned to the release tag. Playbooks and guides, except the FAQ, also have Download PDF.
- Validator, PDF build, bundle build and a GitHub Actions workflow that deploys to GitHub Pages.
